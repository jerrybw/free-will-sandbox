# 超高自由度游戏

## 项目概述
纯前端、可静态部署的 Web 游戏项目。初期内容精简，但建立可扩展基调。

## 技术栈
- **前端框架**: Vite + TypeScript（构建为纯静态文件，可静态部署）
- **代码管理**: GitHub
- **部署**: GitHub Pages（GitHub Actions 自动部署）
- **数据存储**: localStorage / 静态 JSON 配置
- **自动化**: GitHub Actions（定时扫描、部署）

**主题：待定**（2026-09-14 主人更正：甜酒/早餐/下午茶为输入失误，已撤回）

## 配套系统
- 开发进度展示页：需求进度、内容预览、排期、通知日志、黑名单日志、PR/发布状态

## 团队成员
| 角色 | 职责 |
|------|------|
| PM（项目经理 Agent） | 需求收集、评估、评审、排期、通知、黑名单、进度展示、协调沟通 |
| DEV（编程 Agent） | 单线程开发、测试、运维检查、PR、发布、进度更新 |

## 核心流程
1. 用户提交需求/Bug/建议/自开发申请
2. PM 安全初筛 → 评估 → 决定（通过/拒绝/需更多信息）
3. 通过的需求进入排期，PM @DEV 给出任务卡
4. DEV 单线程开发 → 自测 → 运维检查 → 生成 PR
5. 代码自动审批（安全红线 + 质量检查）
6. 审批通过 → 合并 → GitHub Pages 发布
7. PM 更新进度，通知相关人员
